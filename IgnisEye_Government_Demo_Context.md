# IgnisEye — Government Prototype Demo Context

## 1. Project purpose

IgnisEye is a proposed government-facing monitoring system for SIH26162:

**AI-Based Detection and Classification of Industrial Fires and Persistent Thermal Sources Using NASA FIRMS, OSM & Satellite Data**

The demo is a frontend-only prototype. There is no time to train a real ML model or build a production backend.

The prototype demonstrates the proposed workflow using precomputed local demo data and deterministic reference logic.

Core conceptual workflow:

Thermal detections
→ Site identification
→ Industrial / Natural / Unknown
→ Routine / Abnormal
→ Alert / Register / Review
→ Incident history
→ 20 m pinpointing
→ Exercise / threat projection

The application should feel like an early-stage government monitoring system rather than a startup landing page or flashy AI showcase.

## 3. Data status model

The prototype uses three data states.

### DEMO DATA

Pre-created data used to populate the prototype.

### COMPUTED

Values generated by deterministic prototype logic from the demo data.

### SIMULATED

Artificial scenarios created specifically to demonstrate a capability that is not represented by the normal demo dataset.

Simulated incidents must never be presented as real incidents.

---

## 4. ML/model status

No trained model exists in this prototype.

Classification is represented using deterministic reference logic and precomputed results.

The prototype must not claim:

- accuracy
- precision
- recall
- F1
- model confidence
- trained-model performance

The intended future system contains a trained classifier, but the current demo does not.

# 11. Core conceptual behaviour represented by the prototype

The prototype demonstrates the proposed IgnisEye decision structure:

| Source Type | Routine | Abnormal |
|---|---|---|
| Industrial | Persistent Thermal Source / register | Industrial Fire / alert |
| Natural | Recorded | Alert if threatening a facility |
| Unknown | Analyst review | Unverified source alert |

Unknown sources are never forcibly assigned to a known class.

---

# 12. Core demonstration narrative

The prototype is designed to demonstrate:

1. FIRMS-style thermal detections are visible spatially.
2. Multiple detections can be represented as a persistent site.
3. A site can be associated with an industrial facility.
4. Routine industrial heat can remain unalerted.
5. Abnormal behaviour can generate an alert.
6. A long-running incident can remain open rather than becoming normal.
7. A natural fire can be represented as a threat to nearby infrastructure.
8. Unknown sources can be routed for review.
9. A facility can be examined at higher spatial resolution.
10. Outputs can be represented in government-oriented formats.
11. Real, computed and simulated information are explicitly distinguished.
